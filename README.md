# wechat-diary

用 AI 把你的微信聊天记录变成**日记、人物画像和群聊娱乐报告**。

这个项目**没有实现代码**——它是一套提示词工作流 + 两份数据库解密原理文档。
你把文档和提示词喂给任何一个 AI 编程助手（Claude Code / Kimi Code / Cursor …），
它会自己写脚本、自己跑通全流程。我们全程实测过这条路，从加密数据库到一本可翻阅的日记，一气呵成。

## 你能得到什么

- 📔 **个人日记**：AI 读你每天的单聊+群聊发言，每天写一篇日记（自由文体：散文/对话体/书信/打油诗……），附一个双击即开的日记网站
- 🎭 **人物画像**：给自己或群友做画像——话题、风格、情绪模式、10 优点 10 缺点，全部有据可查
- 🏆 **群聊娱乐榜**：舔狗榜、话痨榜、"懂王"榜……损而不恶，熟人局快乐源泉

## 工作流

```
① 解密数据库（技术部分）          ② 导出本人发言           ③ 生成内容
┌─────────────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│ 把 docs/ 里对应平台的文档  │ →  │ prompts/01       │ →  │ prompts/02 日记  │
│ 发给 AI Agent，让它按文档  │    │ 按天导出你的发言   │    │ prompts/03 画像  │
│ 完成密钥捕获与解密        │    │ 到 diary/raw/    │    │ prompts/04 娱乐榜 │
└─────────────────────────┘    └──────────────────┘    │ prompts/05 日记网站│
                                                        └─────────────────┘
```

## 目录

| 文件 | 说明 |
|---|---|
| `docs/WECHAT_MAC_DECRYPT.md` | macOS 微信 4.1+ 解密原理：lldb 断 `CCKeyDerivationPBKDF` 捕获 passphrase + SQLCipher v4 逐页解密（4.1+ 内存扫描已失效，必须用断点方案） |
| `docs/WECHAT_WIN_DECRYPT.md` | Windows 微信/企业微信解密原理：进程内存扫描找 raw key（适用于仍缓存 key 的版本；4.1+ 需改用 KDF 挂钩方案） |
| `prompts/01-导出本人发言.md` | 从解密后的数据库按天导出你的发言 |
| `prompts/02-生成日记.md` | 自由文体日记提示词（附固定四段式变体） |
| `prompts/03-人物画像.md` | 个人/群友画像提示词 |
| `prompts/04-娱乐排行榜.md` | 群聊缺德榜提示词 |
| `prompts/05-生成日记网站.md` | 生成自包含日记网站的提示词 |

## 快速开始

1. 选一个 AI 编程助手，打开一个空目录
2. 先给它 `docs/` 里对应你平台的文档，说："照这个文档，提取我本机微信的数据库密钥并解密聊天数据库"
3. 解密完成后，依次把 `prompts/01` → `02`（→ `03`/`04`）→ `05` 发给它
4. 打开生成的 `diary/index.html`

## 实测背景

本项目提炼自一次完整实战：macOS 15 (arm64) + 微信 4.1.13。
发现 4.1+ 微信不再缓存 raw key 后，方案从"内存扫描"切换为
"lldb 断系统符号 `CCKeyDerivationPBKDF` 在重登瞬间捕获 passphrase"，
随后离线解密全部 39 个库（含 WAL 校验和重算），再用提示词工作流产出
58 篇日记（横跨 2023~2026）、多份人物画像和若干群聊娱乐榜。
全部实现代码由 AI 按上述文档现场编写，未使用任何现成工具。
