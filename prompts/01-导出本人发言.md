# Prompt 01 · 导出本人发言（日记原料）

> 用法：数据库解密完成后，把下面这段提示词发给 AI Agent。
> 目标产物：按天分文件的本人发言记录（日记的原料）。

---

聊天数据库已解密，位于 `<解密产物目录>`（目录结构：`message/message_*.db`、`session/session.db`、`contact/contact.db`）。请完成以下工作：

1. 我的 wxid 是 `<你的wxid>`（不知道的话：数据库目录名里有，或在 message 库的 `Name2Id` 表里找）。
2. 数据库 schema 要点：
   - 每个会话一张消息表，表名 `Msg_<md5(会话username)>`
   - 关键列：`real_sender_id`（发送者，对应 `Name2Id` 表的 rowid）、`create_time`（秒级时间戳）、`local_type`（1=文本）、`message_content`
   - 群消息里别人发的内容带 `微信号:\n` 前缀，我发的没有；部分内容以 BLOB 压缩存储，SQL LIKE 匹配不到，要在应用层解码后过滤
   - `contact/contact.db` 的 `contact` 表有显示名（`nick_name` 昵称、`remark` 备注），群名也在里面
3. 导出**我本人在所有会话（群聊+单聊）中的文本消息**，时间范围 `<起始日期> ~ <截止日期>`，按天分文件写到 `diary/raw/YYYY-MM-DD.txt`，每行格式：

   ```
   HH:MM [会话显示名] 消息内容（换行替换成空格）
   ```

4. 生成 `diary/raw/index.txt` 汇总每天的消息数。
5. 完成后告诉我：覆盖了多少天、共多少条、最早最晚各是哪天。
