# Prompt 05 · 生成日记网站

> 日记写完后，一句话让 AI 给你做个可翻阅的页面。

---

`diary/entries/` 下是我的全部日记（每篇一个 markdown，文件名即日期 YYYY-MM-DD）。请生成一个**自包含的单文件** `diary/index.html`，要求：

1. 所有日记内容内嵌在 HTML 里（JS 对象），双击打开即用——不起服务器、不联网、file:// 直接可用
2. 顶部：**日期选择器**（选了没日记的日期自动跳最近一篇）+ 前一天/后一天按钮 + "最新"按钮
3. 左侧栏：按月分组的日记列表，带星期标注，点击切换（窄屏自动隐藏）
4. 内置一个极简 markdown 渲染器（支持 `#`/`##` 标题、`>` 引用、段落即可），不引外部 CDN
5. 排版做成"纸质感"日记本风格：米白底、纸张卡片、暖色点缀，中文阅读舒适
6. 以后 `entries/` 里新增日记，重新跑一次生成脚本即可（把生成逻辑写成 `build_diary_html.py` 留在项目里）
